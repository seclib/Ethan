# ECLL — Glossary

- **Experience** : tentative technique documentée.
- **Attempt** : une approche conduite dans le cadre d'une expérience.
- **Incident** : problème observé avec impact et résolution.
- **Lesson** : connaissance réutilisable extraite d'une expérience.
- **Evidence** : preuve objective d'un résultat.
- **Status** : état normalisé d'une expérience.
- **Retrieve** : retrouver les expériences pertinentes.
- **Analyze** : les examiner.
- **Compare** : comparer ancien et actuel.
- **Plan** : proposer une stratégie mesurable.
- **Execute** : réaliser dans les autorisations.
- **Evaluate** : vérifier.
- **Capitalize** : enrichir durablement la mémoire.

Les acronymes doivent être expliqués dans le glossaire avant usage.
