# Mémoire inter-sessions Codex — ETHAN

Ce dossier constitue la mémoire documentaire minimale pour reprendre un travail Codex sans créer de doublon avec les plans et rapports existants.

## Fichiers

- `PROJECT_STATE.md` : état courant vérifié du dépôt, prochaine tâche et blocages.
- `DECISIONS.md` : décisions validées, propositions non validées, hypothèses et dette technique.
- `sessions/YYYY-MM-DD.md` : archives datées d'une session.

## Conventions

- Ne pas inventer de résultats, de décisions ou de validations.
- Séparer clairement les faits vérifiés, les hypothèses et les recommandations.
- Ne jamais archiver de secrets, tokens, mots de passe, clés privées ou données personnelles.
- Réutiliser les structures existantes (`docs/plans/execution/`, `docs/adr/`, rapports datés) plutôt que créer des doublons.

## Source de vérité

Les capacités ETHAN restent dans le Core et le code associé (`core/`). Ces fichiers de mémoire ne contiennent que du contexte documentaire.
